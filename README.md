# 루틴 캘린더

직장인의 반복 일정을 버튼 한 번으로 넣는 아이폰·아이패드용 캘린더 앱입니다. 데이터는 앱 안(SwiftData)에만 저장되고, 아이폰 기본 캘린더와는 연동하지 않습니다.

## 주요 기능

- **점심 / 저녁 빠른 입력**: 버튼을 누르고 이름(예: 김대리)만 쓰면 기본 시간(점심 12:00–13:00, 저녁 18:30–20:00)으로 바로 저장됩니다. 일정 제목은 `점심 · 김대리` 형태가 됩니다.
- **나만의 태그**: 예를 들어 `운동` 태그를 만들어 두면 누르는 즉시 정해둔 시간(기본 19:00–20:00)에 일정이 생깁니다.
- **재판 태그**: 기본 시간이 없는 태그로, 누를 때 시간(과 사건명)을 직접 고릅니다.
- **태그 설정**: 태그마다 이름, 색, 아이콘, 기본 시간 사용 여부, 시작·종료 시간, 이름 입력 여부를 바꿀 수 있습니다. 태그 관리 화면에서 순서 변경과 삭제도 됩니다.
- **빠른 입력 팁**: 태그 버튼을 길게 누르면 "다른 시간으로 추가"와 "태그 편집"이 나옵니다. 추가 직후 아래에 뜨는 "실행 취소"로 바로 되돌릴 수 있습니다.
- **일반 캘린더 기능**: 월간 달력(좌우로 넘기기, 일정 색 점 표시), 날짜별 일정 목록, `+` 버튼으로 단발성 일정 추가(하루 종일, 메모, 태그 지정), 일정 눌러서 편집, 밀어서 삭제.
- **아이패드**: 가로 화면에서 왼쪽 달력, 오른쪽 하루 일정으로 나눠 보여줍니다.

빠른 입력은 항상 달력에서 **선택한 날짜**에 들어갑니다.

## 실행 방법

1. Xcode 16 이상에서 `RoutineCalendar.xcodeproj`를 엽니다.
2. 프로젝트 > `RoutineCalendar` 타깃 > Signing & Capabilities에서 Team을 본인 Apple ID로 고릅니다. 필요하면 Bundle Identifier(`com.seunghee.RoutineCalendar`)도 바꿉니다.
3. 아이폰이나 아이패드(iOS 17 이상) 또는 시뮬레이터를 고르고 실행합니다.

처음 실행하면 점심, 저녁, 운동, 재판 태그가 자동으로 만들어집니다.

## 구조

```
RoutineCalendar/
  RoutineCalendarApp.swift      앱 진입점, SwiftData 컨테이너
  Models/                       CalendarEvent(일정), QuickTag(빠른 입력 태그)
  Support/                      날짜 도우미, 색상, 기본 태그 생성
  Views/                        달력, 하루 목록, 빠른 입력, 일정·태그 편집 화면
```
